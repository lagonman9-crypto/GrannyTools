Install in 5 steps

GrannyTools is a BepInEx plugin. You install BepInEx into the game folder once, then drop the mod in.

Get the right BepInEx

Granny runs on Unity 6 with IL2CPP, so it needs the bleeding-edge BepInEx 6, the Unity IL2CPP build for Windows x64 — exactly build 793:

BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.793+dbc82f0.zip
Download BepInEx (build 793) All BepInEx bleeding-edge builds
Don't use BepInEx 5, the “Unity.Mono” build, or the stable 6.0.0-pre releases from GitHub — the mod won't load with them. On the builds page, open build #793 and pick BepInEx-Unity.IL2CPP-win-x64.

Open the Granny folder

In Steam: right-click Granny → Manage → Browse local files. This is the folder with Granny.exe in it (usually C:\Program Files (x86)\Steam\steamapps\common\Granny).

Extract BepInEx into it

Unzip everything from the BepInEx zip straight into that folder, next to Granny.exe (not into a sub-folder). It should look like this:

Granny/ ├── BepInEx/ ├── dotnet/ ├── doorstop_config.ini ├── winhttp.dll ├── Granny.exe ├── Granny_Data/ └── …

Start the game once

Launch Granny from Steam and wait at the logo/menu. The first start takes a minute or two while BepInEx prepares the game — it can look frozen, that's normal. When the main menu shows up, close the game.

After this, the folder BepInEx/plugins exists (create it if it doesn't).

Add GrannyTools and play

Put GrannyTools.dll into Granny/BepInEx/plugins/, start the game and press F1 to open the menu.

FAQ & troubleshooting

 

F1 does nothing / no menu
  • Make sure BepInEx is the IL2CPP x64 build 793 (step 1) and that winhttp.dll sits right next to Granny.exe.
  • Make sure GrannyTools.dll is in BepInEx/plugins.
  • Open BepInEx/LogOutput.log and look for GrannyTools and any red errors.
The first launch is stuck

The first start with BepInEx builds files for the game and can take a couple of minutes. Wait for it; later starts are fast.

Can I use it for leaderboard runs?

Check your leaderboard's rules. The timer, splits and skips that don't change gameplay are usually fine for personal practice; ESP, god mode, speed changes and the custom difficulties are for practice and fun, not for submitted runs.

Custom menu, ambience and chase music

Put WAV files named GrannyTools_menu_music.wav, GrannyTools_ambience.wav and GrannyTools_chase.wav in BepInEx/config, then switch them on in Misc → Menu music.

How do I uninstall?

Delete BepInEx/plugins/GrannyTools.dll. To remove BepInEx completely, also delete winhttp.dll, doorstop_config.ini, dotnet and the BepInEx folder. You can also use Steam's “Verify integrity of game files”.

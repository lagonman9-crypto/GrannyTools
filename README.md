# GrannyTools

A free speedrun, practice and mod menu for the PC (Steam) version of Granny. Press **F1** in game.

**Website:** https://lagonman9-crypto.github.io/GrannyTools/
**Download:** [GrannyTools.dll (latest)](https://github.com/lagonman9-crypto/GrannyTools/releases/latest/download/GrannyTools.dll)

## Install

1. Download **BepInEx 6 bleeding-edge build 793, Unity IL2CPP, Windows x64**:
   [`BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.793+dbc82f0.zip`](https://builds.bepinex.dev/projects/bepinex_be/793/BepInEx-Unity.IL2CPP-win-x64-6.0.0-be.793%2Bdbc82f0.zip)
   (not BepInEx 5, not the Mono build, not the 6.0.0-pre GitHub releases).
2. Steam → right-click Granny → Manage → Browse local files.
3. Extract the BepInEx zip into that folder, next to `Granny.exe`.
4. Start the game once and wait for the main menu (the first start takes a minute or two), then close it.
5. Put `GrannyTools.dll` in `Granny/BepInEx/plugins/`, start the game and press **F1**.

## Features

- Speedrun timer with auto-splits, PB, golds, sum of best, pace, run history and a PB ghost — per difficulty
- Skips: fast wake-up, fast doors, instant crawling-mom key, fall get-up skip, instant gas can / bear traps
- Route guide that highlights the next thing you need, with a walking path
- New difficulties: Easy + Extreme Granny, Easy ++, Mirror, Terror
- Practice tools, FPS boost, ESP/visuals, stream-safe mode, menu search, custom music
